## Shared patterns
- One hero object with motion (cursor tilt, orbit, parallax), not many small animations.
- Serif display face against a plain sans/mono for labels.
- Scroll-driven reveals: word-by-word manifesto, count-up stats.
- Glass pills for nav and CTAs; status chips in the header.
